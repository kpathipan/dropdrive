# DropDrive 6.25.1 — Mac + Windows

## แก้ไข
- Windows: วางลิงก์ซ้ำแล้วเปิดรายการให้ตรวจ/ยืนยันต่อได้ ไม่ล้างลิงก์แล้วเงียบไป หากงานกำลังดาวน์โหลดอยู่จะแจ้งและไม่เพิ่มงานซ้ำ
- Windows: ดาวน์โหลดโฟลเดอร์ Google Drive แล้วเก็บไฟล์ไว้ใต้ชื่อโฟลเดอร์ต้นทาง พร้อมโฟลเดอร์ย่อย ไม่กระจายลงโฟลเดอร์ปลายทาง และไม่สร้างชื่อซ้อนเมื่อเลือกโฟลเดอร์ชื่อเดียวกันไว้แล้ว
- Mac และ Windows: แบ่งไฟล์ใหญ่เป็นส่วนย่อยขนาดไม่เกิน 8 MB ใช้จำนวนการเชื่อมต่อจำกัด และต่อเฉพาะส่วนที่ขาดเมื่อการเชื่อมต่อช้าผิดปกติหรือขาดช่วง ลดการรอส่วนท้ายเส้นเดียวโดยไม่สร้างไฟล์สำเนาเพื่อรวมภายหลัง
- เพิ่มการตรวจข้อมูลตอบกลับและความถูกต้องของไฟล์ ป้องกันการบันทึกไฟล์ไม่ครบเป็นไฟล์สำเร็จ

## ปรับให้ทั้งสองระบบไปด้วยกัน
- ใช้เลขเวอร์ชันและชุดปล่อยเดียวกัน แยกไฟล์ติดตั้งตามระบบได้ถูกต้อง
- ตรวจอัปเดตอัตโนมัติทุก 24 ชั่วโมง หรือกดตรวจเองได้ทันที
- Windows ใช้โลโก้ต้นฉบับเดียวกับ Mac พร้อมโฟลเดอร์โปรด กฎปลายทาง และภาพตัวอย่างแบบจำกัดหน่วยความจำที่เลื่อนได้เกิน 100 ไฟล์
- Google Drive ใช้ได้ทั้งไฟล์สาธารณะแบบไม่ล็อกอิน และล็อกอินหลายบัญชีตามสิทธิ์ของแต่ละบัญชี

## หมายเหตุ
- ความเร็วและการเข้าถึงเว็บวิดีโอยังขึ้นกับต้นทาง เครือข่าย และสิทธิ์ของลิงก์ ไม่รับรองว่าลิงก์ที่ถูกลบ ถูกจำกัดสิทธิ์ หรือถูกปฏิเสธเครือข่ายจะดาวน์โหลดได้
- การทดสอบ Google หลายบัญชีบน Windows ครอบคลุมขั้นตอนและที่เก็บข้อมูลผ่านการทดสอบอัตโนมัติ แต่ยังไม่ได้ยืนยันการใช้งานหลายบัญชีจริงครบทุกขั้นตอนบนเดสก์ท็อป Windows
- Windows เป็นหน้าต่างขนาดเล็ก/ถาดระบบ ส่วน Mac อยู่บนเมนูบาร์ การเลือกโฟลเดอร์และจัดเก็บบัญชีใช้ระบบของแต่ละ OS
- ตัวติดตั้ง Windows ยังไม่มีใบรับรองเซ็นโปรแกรม Windows อาจแสดงคำเตือนผู้เผยแพร่ที่ไม่รู้จัก
- Mac ให้ยืนยันก่อนติดตั้ง ส่วน Windows ติดตั้งเมื่อไม่มีงานใช้งานค้าง ไม่รีสตาร์ตตัดงานดาวน์โหลด
