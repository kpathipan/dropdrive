# DropDrive 6.25.2 — Mac + Windows

## แก้ไข
- Mac: แก้การล็อกค้างเมื่อพักหรือยกเลิกงานขณะการเชื่อมต่อดาวน์โหลดจบหรือผิดพลาด
- Mac: บันทึกคิวลงไฟล์แบบ atomic พร้อมสำรองล่าสุด และยังอ่านคิวจากรุ่นเดิมได้ ลดความเสี่ยงคิวหายเมื่อแอปถูกปิดฉับพลัน
- Mac: รักษารายการที่รอกู้คืนเมื่อมีงานใหม่เข้ามาก่อนผู้ใช้ตอบข้อความกู้คืนคิว
- Windows: เพิ่มการทดสอบยกเลิกงานหลายการเชื่อมต่อแล้วเริ่มใหม่ ตรวจข้อมูลครบและไม่มีงานเบื้องหลังค้าง ไม่พบข้อผิดพลาดแบบล็อกค้างของ Mac ในการทดสอบนี้

## ข้อจำกัด
- รุ่นนี้เน้นแก้การค้างและความทนทานของคิว ไม่รับประกันการกู้คืนรายการที่สูญหายก่อนติดตั้ง
- การเข้าถึงลิงก์ยังขึ้นกับเครือข่ายและสิทธิ์ต้นทาง การทดสอบอัตโนมัติไม่ได้แทนการทดสอบบัญชีจริงทุกกรณี
- Windows ยังไม่มีใบรับรองผู้เผยแพร่ ตัวติดตั้งอาจแสดงคำเตือนของ Windows
- ไม่ติดตั้งทับแอป Mac ที่ผู้ใช้กำลังดาวน์โหลดอยู่ ให้จบงานก่อนกดอัปเดต
