# DropDrive 6.25.3 — Windows hotfix

- แก้สถานะดาวน์โหลดสำเร็จถูกเปลี่ยนเป็นไม่สำเร็จเพราะบันทึกประวัติ สถิติ หรือเปิดโฟลเดอร์ไม่สำเร็จ
- หากตัวดาวน์โหลดยืนยันไฟล์สุดท้ายแล้ว แต่แจ้งข้อผิดพลาดตอนจบ จะตรวจไฟล์ก่อน หากผ่านจะแสดงสำเร็จพร้อมข้อความเตือนแยก ไม่สั่งโหลดซ้ำอัตโนมัติ
- ไม่ใช้กฎนี้กับเพลย์ลิสต์ที่ผิดพลาดหรือไฟล์ที่ไม่ผ่านการตรวจ เพื่อไม่รายงานงานที่ไม่ครบว่าสำเร็จ
- อ่านชื่อและพาธภาษาไทยจากตัวดาวน์โหลดด้วย UTF-8 ทั้งต้นทางและปลายทาง
- หากจัดชื่อไฟล์ไม่ได้ ยังคงไฟล์และพาธเดิมที่เปิดใช้งานได้
- แยกข้อความตรวจไฟล์หมดเวลาออกจากการกดพักของผู้ใช้

รุ่นนี้แก้เฉพาะ Windows ตามคำขอผู้ดูแล ไม่เปลี่ยนแอป Mac และไม่รับรองว่าจะข้ามการปฏิเสธลิงก์/การตรวจบอตของเว็บได้ ยังไม่มีข้อความผิดพลาดจากเครื่องผู้ใช้เพื่อยืนยันว่าสาเหตุเฉพาะเครื่องตรงกับกรณีใด

ผ่านการทดสอบอัตโนมัติสำหรับความผิดพลาดหลังดาวน์โหลด ไฟล์เสีย/ผลลัพธ์หาย เพลย์ลิสต์ไม่ครบ และการบันทึกสถิติที่ถูกล็อก ส่วนการทดสอบเว็บจริงขึ้นกับเครือข่ายและสิทธิ์ต้นทาง

ตัวติดตั้ง Windows ยังไม่มีใบรับรองผู้เผยแพร่ Windows อาจแสดงคำเตือน เมื่อตรวจอัปเดตจากในแอปจะรักษาคิวและการตั้งค่าเดิม
