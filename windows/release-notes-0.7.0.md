# DropDrive Windows 0.7.0

ยึดการทำงานของ Mac 6.24.4 โดยใช้หน้าต่างเล็กแทน menubar และใช้งานได้โดยไม่บังคับล็อกอิน

สถานะ: ฉบับเตรียมเผยแพร่ ต้องตั้งค่าและทดสอบ Google Desktop OAuth จริงก่อนปล่อยรุ่นนี้

- กลับหน้าหลักว่างแล้วหน้าต่างย่อกลับขนาดเล็ก ตั้งค่าอยู่ในหน้าต่างเดิม
- เพิ่มบัญชี Google ได้หลายบัญชีแบบสมัครใจ เพื่อดาวน์โหลดไฟล์ที่บัญชีมีสิทธิ์ เลือกบัญชีเริ่มต้นได้ และรีเฟรชรายการเดิมหลังล็อกอิน ส่วนไฟล์สาธารณะยังโหลดได้โดยไม่ล็อกอิน
- ไทย/อังกฤษ การ์ด 3 ขนาด/รายการ เลือกทั้งหมด/รายไฟล์/เฉพาะใหม่หรือเปลี่ยนแปลง พร้อม Space ดูภาพตัวอย่างในหน้าเดิม
- รูปชุด TikTok พร้อมไฟล์เสียงประกอบ เลือกรูปที่จะดาวน์โหลดได้ ไม่แปลงรูปทั้งหมดเป็นวิดีโอ
- พักและเดินคิวทั้งชุด เลือกดาวน์โหลดหลายลิงก์ ตรวจลิงก์ซ้ำแม้ URL แชร์ต่างกัน จำ MP3 แยกตามแพลตฟอร์ม
- ลองใหม่อัตโนมัติแบบจำกัดเมื่อเน็ตหลุด และกู้คิวเมื่อโฟลเดอร์ปลายทางกลับมา
- แจ้งเตือน Windows เมื่อเสร็จ/ต้องตรวจสอบ พร้อมเสียงที่ปิดได้ เปิดพร้อม Windows และคีย์ลัด Ctrl+Shift+D
- รับลิงก์จากมือถือผ่านโฟลเดอร์ซิงก์ที่เลือกเอง ตั้งให้ดาวน์โหลดอัตโนมัติได้ เก็บไฟล์ลิงก์ที่ประมวลผลแล้วใน Processed
- โฟลเดอร์ปลายทางล่าสุด สถิติในเครื่อง จำกัดความเร็วแบบกำหนดเอง และกันเครื่องหลับเฉพาะขณะดาวน์โหลด
- ตรวจไฟล์วิดีโอ/MP3 ก่อนแจ้งว่าเสร็จ ตัดรหัสงานยาวออกจากชื่อไฟล์โดยเปลี่ยนชื่อ ไม่คัดลอกไฟล์ซ้ำ
- ป้องกันเปิดแอปซ้ำ และอัปเดตทับรุ่นเดิมทุก 24 ชั่วโมง/กดตรวจเอง โดยรอให้งานว่าง

ข้อจำกัดที่ควรรู้: การเทียบไฟล์ใหม่/เปลี่ยนแปลงเมื่อไม่ล็อกอินอาศัยข้อมูลสาธารณะ จึงอาจตรวจไม่พบการแก้เนื้อหาที่ชื่อ/ข้อมูลไม่เปลี่ยน พรีวิวก่อนโหลดเป็นภาพ/ไอคอนเหมือน Mac รุ่นอ้างอิง ไม่เล่นวิดีโอจากลิงก์ และเว็บไซต์อาจปฏิเสธการดาวน์โหลดตามสิทธิ์ ภูมิภาค หรือข้อจำกัดเครือข่าย
