# DropDrive Windows 0.6.0

ปรับโครงหน้า Windows ให้ใกล้ Mac มากขึ้น เป็นหน้าต่างเล็ก ธีมมืด
ภาษาไทย พร้อมฟอนต์ไทยในตัว และตั้งค่าภายในหน้าต่างเดิม

- แยกหน้าตรวจรายการก่อนดาวน์โหลด: ภาพปก ชื่อไฟล์ ปลายทาง และ MP3/คุณภาพ
- ตัวเลือกคำบรรยาย ตัดช่วงวิดีโอ แยกบท และบันทึกปก
- เลือกไฟล์แบบการ์ด 3 ขนาดหรือรายการ ช่องเลือกทั้งหมด/รายไฟล์ และค้นหา
- ปุ่มดาวน์โหลดเมื่อว่าง เปลี่ยนเป็นเข้าคิวเมื่อมีงาน
- Drive สาธารณะรองรับรายการในโฟลเดอร์ โฟลเดอร์ย่อย และส่งออกเอกสาร
- หยุด/ดาวน์โหลดต่อ ลองใหม่ และเรียงคิว พร้อมบันทึกปลายทางต่อรายการ
- ประวัติค้นหา เปิดไฟล์ เปิดตำแหน่ง คัดลอกลิงก์ และดาวน์โหลดซ้ำ
- ตัวเลขความคืบหน้าไม่เปลี่ยนความกว้างหน้าต่าง
- ตรวจอัปเดตทุก 24 ชั่วโมงขณะเปิดแอป และรอตอนว่างก่อนติดตั้ง
- ใส่ตัวช่วย YouTube/FFmpeg มาในตัว และใช้เส้นทางวิดีโอต้นฉบับของ TikTok

ทดสอบอัตโนมัติทั้ง UI ภาษาไทยและการกดเลือกไฟล์บน Windows
รวมถึงดาวน์โหลดผ่านคิวจริงด้วยข้อมูลทดสอบ HTTP
ทดสอบ Drive ออนไลน์ได้ทั้งอ่านโฟลเดอร์และส่งออกไฟล์ PPTX

ข้อจำกัด: ยังไม่เทียบเท่า Mac ทุกฟีเจอร์ โดยเฉพาะ Google หลายบัญชี/
ไฟล์จำกัดสิทธิ์, Drive ดาวน์โหลดเฉพาะไฟล์เปลี่ยน, inbox จากมือถือ,
การแจ้งเตือนระบบ/เปิดพร้อมเครื่อง และพรีวิววิดีโอแบบเล่นในแอป
(Space แสดงภาพตัวอย่าง) รวมถึง TikTok โพสต์รูปหลายภาพ
การทดสอบนี้ไม่ได้ยืนยันว่าลิงก์ทุกลิงก์จากทุกแพลตฟอร์มใช้งานได้
