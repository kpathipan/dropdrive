# DropDrive 6.25.4 — Mac + Windows

## เพิ่มเติม
- เมื่อพบลิงก์ที่เคยดาวน์โหลดแล้ว เพิ่มปุ่ม **แสดงใน Finder** บน Mac / **แสดงใน Explorer** บน Windows เพื่อเปิดตำแหน่งไฟล์หรือโฟลเดอร์เดิม
- เมื่อพบชื่อซ้ำที่ปลายทาง สามารถเปิดดูรายการเดิมก่อนดาวน์โหลดได้ โดยไม่เขียนทับไฟล์เดิม
- ตรวจว่าตำแหน่งยังอยู่จริงก่อนเปิด หากไฟล์ถูกย้าย ลบ หรือไดรฟ์ถูกถอด จะแจ้งให้ทราบ ไม่เริ่มดาวน์โหลดหรือเปลี่ยนตัวเลือก MP3
- รองรับภาษาไทยและอังกฤษ ใช้ประวัติตำแหน่งที่แอปบันทึกไว้ ไม่สแกนทั้งเครื่อง
- Windows รวมการแก้การแจ้งดาวน์โหลดสื่อไม่สำเร็จผิดพลาดจาก 6.25.3 ไว้แล้ว

## ข้อจำกัดที่ยังมี
- รุ่นนี้เพิ่มการเปิดตำแหน่งไฟล์ซ้ำ ไม่ได้แก้ Instagram ที่ต้นทางจำกัดอายุ/สิทธิ์ และไม่รับประกันว่าทุกลิงก์จะดาวน์โหลดได้โดยไม่ล็อกอิน
- หากประวัติตำแหน่งถูกล้าง หรือไฟล์เดิมถูกย้าย แอปไม่ค้นหาไฟล์แทนทั่วเครื่อง
- ยังมีรายงานปัญหาวางหลายลิงก์ซ้ำบน Mac ที่อยู่ระหว่างแก้ไข ใช้การวางทีละลิงก์หากพบอาการ
- ผลทดสอบอัตโนมัติไม่ใช่การรับรองครบทุกบริการหรือบัญชีจริงทุกกรณี
- Windows ยังไม่มีใบรับรองผู้เผยแพร่; Mac ใช้ใบรับรอง Apple Development เดิม ไม่ได้ notarize ตัวติดตั้งใหม่อาจแสดงคำเตือนของระบบ
