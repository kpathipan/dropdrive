One-time setup in Terminal

DropDrive isn't notarized by Apple yet, so macOS needs one command before it'll open.

1

Press ⌘ Space, type Terminal, press Return

2

Copy this command

xattr -d com.apple.quarantine /Applications/DropDrive.app
3

Paste into Terminal and press Return, then reopen DropDrive

This only has to be done once, right after installing.
